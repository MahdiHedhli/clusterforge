# SEC-200 practical: The contractor access request

**Status:** Draft assessment; runtime not verified. **Suggested duration:** three 30-minute blocks.

## Prerequisites

SEC-200 lessons or equivalent evidence, the [shared practical](../curriculum/practicals/levels-200-300/README.md), and access to approved authorization/network evidence. Use the [common rubric](README.md).

## Customer brief

A temporary diagnostics workload needs to read configuration in one project and call that project's web service. It must not read Secrets, create workloads, change permissions or access other project services. Access must have an owner, an expiry/review process and useful audit evidence.

## Required work

Design the identity and scoped authorization. Explain which lifecycle actions belong to provisioning, authentication, authorization and the downstream service. Implement the approved namespaced role and network control using synthetic identities. Predict and test the required operation and at least three prohibited operations. Distinguish an impersonation authorization check from actual token authentication.

Provide an auditability plan with one observed event when a sink is available. Explain the secret/transport boundaries and propose a temporary exception without granting it automatically. Identify who will remove the access and how removal will be verified.

The instructor introduces one unseen role-subject or policy-selector defect. Diagnose it without using a broad role or allow-all policy.

## Passing evidence

Submit the requirement-to-control matrix, expected/observed results, identity lifecycle, evidence limitations and exception/offboarding plan. Apply the common rubric. Mark unavailable live identity, encryption or audit capabilities separately; do not substitute a synthetic packet for implementation qualification.

## Cleanup and next step

Restore the baseline, remove exercise-created bindings/policies and record the next security competency. The conceptual portion may be completed without every external platform, but missing implementation evidence remains an open gate.
